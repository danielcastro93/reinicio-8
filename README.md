# Reinicio 8

Web app mobile (PWA) para un plan de 8 semanas de fuerza y condición con cuidado de rodilla. Funciona offline y se instala en el iPhone desde Safari con Compartir > Agregar a pantalla de inicio.

- Todo se guarda en el dispositivo (localStorage), sin cuentas ni servidor.
- No es una app médica y no sustituye la valoración de un profesional.
